ELSEWHERE PC - iPhone helyszin-szimulalo (USB)

ELSO ALKALOM
1. Telepitsd a Pythont (python.org, pipald be: "Add python.exe to PATH").
2. Telepitsd az "Apple Devices" appot a Microsoft Store-bol (vagy iTunes).
3. Dupla katt: install.bat   (telepiti a pymobiledevice3-at)
4. iPhone: Beallitasok > Adatvedelem es biztonsag > Fejlesztoi mod: BE, ujrainditas.
5. Dugd be a telefont kabellel, oldd fel, Trust (Megbizom).

HASZNALAT
1. Dupla katt: start.bat  (rendszergazda jogot kerni fog a tunneld miatt)
2. Megnyilik a bongeszoben a terkep. Kattints egy helyre, "Teleport ide".
3. "Valodi GPS" gomb: visszaall a valodi hely.
4. A hely addig tartva marad, amig a program fut es a telefon be van dugva.

KIPROBALAS TELEFON NELKUL:  python elsewhere_pc.py --demo
